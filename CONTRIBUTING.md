# Contributing

Thanks for helping improve Research Before Build.

## Good contributions

- evidence-backed research modules
- portability fixes
- eval scenarios
- failure-mode checklists
- better source-validation rules
- framework-specific adapters kept outside the core orchestration logic

## Pull request checklist

- [ ] The change solves a concrete research/build failure mode.
- [ ] New factual guidance cites or names authoritative sources in the PR description.
- [ ] Core `SKILL.md` stays portable and reasonably concise.
- [ ] Tool-specific behavior has a fallback.
- [ ] No third-party skill text was copied verbatim without compatible licensing and attribution.
- [ ] Examples do not encourage deceptive human impersonation.

## Style

Prefer imperative, testable instructions over essays. A skill should provide missing procedure, not explain the entire domain.

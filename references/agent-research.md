# Agent Research Checklist

Use for assistants, copilots, SDRs, receptionists, support agents, multi-agent systems and voice agents.

## Architecture

- framework/version
- orchestration model
- model/provider abstraction
- session lifecycle
- state persistence
- memory model
- knowledge/RAG
- tools and permissions
- structured output
- retries and idempotency
- background jobs/queues
- human handoff

## Production

- observability
- tracing
- evals
- latency
- token/cost controls
- deployment
- secret management
- data retention
- privacy/security
- rate limits
- failure recovery

## Conversation UX

- concise defaults
- context continuity
- clarification strategy
- escalation rules
- channel constraints
- multilingual needs
- truthful identity behavior

Natural language is desirable. False human impersonation is not.

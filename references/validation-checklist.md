# Validation Checklist

Before building:

- [ ] Request classified
- [ ] Existing skills/templates searched
- [ ] Primary/current sources checked
- [ ] Failure/limitation search performed
- [ ] Material claims backed by evidence
- [ ] Contradictions resolved or exposed
- [ ] At least one alternative compared
- [ ] Chosen approach documented
- [ ] Risks and mitigations listed
- [ ] Build blueprint ready
- [ ] One next action selected

For commercial projects also verify:

- [ ] ICP is explicit
- [ ] painful workflow is evidenced
- [ ] substitute/competitor set is known
- [ ] pricing evidence exists
- [ ] acquisition path is plausible
- [ ] support/fulfillment burden is understood

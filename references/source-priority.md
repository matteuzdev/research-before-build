# Source Priority

## Technical claims

Prefer:

1. official docs and specifications
2. first-party source code and APIs
3. maintained official examples
4. standards and strong independent technical references
5. GitHub issues/discussions for real friction
6. community posts for experience signals
7. generic SEO content only for discovery

## Market claims

Use a different evidence stack:

1. direct customer evidence
2. competitor product/pricing pages
3. reviews and complaint patterns
4. job posts and implementation requests
5. credible market datasets/reports
6. communities and forums
7. ads and public campaigns as demand/positioning signals

## Freshness

For fast-moving frameworks, verify version/date before relying on familiar patterns.

## Confidence

- High: primary source or 3+ credible sources agree
- Medium: 2 credible independent sources agree
- Low: one source, stale evidence, or conflict

Never equate popularity with truth.

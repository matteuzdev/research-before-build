# Website Research Checklist

## Business

- primary conversion goal
- traffic source
- target customer
- core offer
- proof/trust signals
- objections
- CTA priority

## Experience

- mobile-first hierarchy
- navigation
- accessibility
- speed
- form friction
- WhatsApp/booking behavior
- visual proof
- copy clarity

## Discoverability

- search intent
- title/meta structure
- schema
- local SEO
- AEO/GEO when relevant
- indexability
- analytics events

## Technical

- stack
- hosting
- domain/DNS
- CMS need
- integrations
- privacy/cookie requirements
- maintenance model

Do not begin from aesthetics alone.

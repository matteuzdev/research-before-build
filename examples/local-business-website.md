# Example — Local-business website

Prompt:

> Build a website for a local HVAC company that turns Google traffic into WhatsApp leads.

Expected research:

- local search intent
- competitor sites
- service pages
- trust/proof signals
- mobile conversion hierarchy
- WhatsApp CTA behavior
- local SEO/schema
- performance
- deployment/domain
- measurement

Expected output:

Decision → evidence → sitemap/content hierarchy → design/conversion system → technical blueprint → next action.

# Example — Python + Agno customer-facing agent

Prompt:

> Build a production-ready Python + Agno receptionist that talks to customers on WhatsApp.

Expected behavior:

1. classify as `AGENT + AUTOMATION`
2. search current Agno docs and maintained examples
3. check skills/reusable patterns
4. research sessions, memory, knowledge, tools, handoff, retries, observability and deployment
5. research WhatsApp channel constraints
6. search known failure modes/issues
7. compare at least one realistic alternative architecture
8. produce blueprint before code

The conversation layer should feel natural and concise, but it must not falsely claim to be human.
